# Lightning vs Wind Pong

Web game arcade realizzato in HTML, CSS e JavaScript puro, pronto per GitHub Pages.

## Funzioni V1

- Lightning vs CPU
- Lightning vs Wind a 2 giocatori sullo stesso dispositivo
- Difficoltà CPU: Facile, Media, Difficile
- Controlli tastiera e touch
- Effetti particellari e scie luminose
- Audio sintetizzato con Web Audio API
- Primo a 10 punti
- Pausa, rivincita, fullscreen
- Statistiche vittorie salvate nel browser
- Service Worker per uso offline/PWA di base

## Controlli

- Lightning: W / S
- Wind: Freccia su / Freccia giù
- Pausa: P
- Smartphone: trascina verticalmente nella metà del campo corrispondente

## Pubblicazione su GitHub Pages

1. Crea un repository pubblico, ad esempio `lightning-wind-pong`.
2. Carica tutti i file di questa cartella nella root del repository.
3. Apri **Settings → Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**.
5. Seleziona branch `main` e cartella `/ (root)`.
6. Salva.

Dopo alcuni secondi/minuti il gioco sarà disponibile su:

`https://TUO-USERNAME.github.io/lightning-wind-pong/`
